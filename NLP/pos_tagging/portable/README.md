# Портативная POS-модель для Windows

`pos_tagger.exe` — самодостаточная 64-битная Windows-программа. Внутри уже есть лучшая по полному тесту CNN, словарь,
Python runtime и ONNX Runtime. На другом компьютере **не нужно устанавливать Python, TensorFlow, Keras, NumPy или
ONNX Runtime**.

## Самый простой способ

1. Скопируйте `pos_tagger.exe` на Windows x64 ноутбук.
2. Запустите `run_pos.bat`, введите слово или предложение и нажмите Enter.

Или откройте PowerShell в этой папке:

```powershell
./pos_tagger.exe --text "Что делать, если пароль забыт?"
```

Программа работает локально, подключение к интернету не требуется. Используется CPU.

## Результат

Для каждого слова выводится UPOS-тег и уверенность модели. Внутрь exe включена та же CNN, что получила на `nerus_lenta`
accuracy 0.9566 и macro-F1 0.8317. Сохранённый ONNX совпал с исходной Keras-моделью в проверке: максимальное
различие вероятностей было около `1.2e-7`.

## Ограничения

- Программа собрана для **Windows x64**. Для Linux/macOS используйте ONNX-файл и `predict_pos_onnx.py`.
- Это inference-вариант: он запускает только лучшую single-task CNN. Чтобы заново обучать CNN/LSTM/GRU или сравнивать
  их, нужен полный ноутбук и окружение из `requirements.txt`.
- Файл не подписан сертификатом издателя, поэтому Windows SmartScreen может показать предупреждение о неизвестном
  издателе.
