# Определение частей речи (POS-tagging)

В проекте есть две версии задания:

- `pos_tagging.ipynb` — исходная учебная версия на небольших текстах из задания 1 и разметке `pymorphy3`;
- `pos_tagging_syntagrus.ipynb` — расширенная версия на ручной разметке SynTagRus.

## Расширенная версия

### Данные

Обучение выполняется на `data/ru_syntagrus-ud-2.0-morpho-train.txt` в формате CoNLL-U:

- 54 529 предложений;
- около 962 тысяч токенов;
- ручная разметка Universal Dependencies (17 тегов UPOS).

Проверка выполняется на `data/nerus_lenta.conllu.gz` — новостном корпусе Lenta.ru из NeRus. Он не используется для
обучения, поэтому показывает перенос на другой источник текста. Для экономии времени читаются первые 10 000
предложений (около 180 тысяч токенов), а не весь архив размером около 2 ГБ.

Размеры входа фиксированы: 40 слов в предложении и 20 символов в слове. Длинные предложения режутся на фрагменты,
короткие дополняются `PAD`.

### Что улучшено

1. **Более качественная разметка.** Вместо автоматических тегов `pymorphy3` используются ручные UPOS-метки SynTagRus.
2. **Больше данных.** Обучающий корпус примерно в 300 раз больше исходного учебного набора.
3. **LSTM и GRU.** Символьная CNN строит вектор слова, затем BiLSTM или BiGRU учитывает порядок и контекст слов
   предложения. Это быстрее, чем рекуррентно обрабатывать каждый символ, и лучше использует контекст.
4. **Балансировка классов.** В loss добавлены мягкие веса редких частей речи. Дополнительно считается macro-F1,
   поэтому качество редких тегов не скрывается частыми `NOUN` и `PUNCT`.
5. **Ансамбль.** Вероятности CNN, LSTM и GRU объединяются с весами, выбранными на validation SynTagRus.
6. **Многозадачность.** `lstm_multi.keras` одновременно предсказывает UPOS и 10 наиболее частых морфологических
   признаков: `Number`, `Case`, `Gender`, `Animacy`, `Degree`, `Aspect`, `VerbForm`, `Voice`, `Tense`, `Mood`.
   Для отсутствующих в UD признаков используется маскирование.

### Результаты

Итоговая таблица рассчитана на `nerus_lenta` по 181 663 токенам:

| Модель | Accuracy | Macro-F1 |
|---|---:|---:|
| CNN baseline | **0.9566** | **0.8317** |
| BiLSTM | 0.9255 | 0.7977 |
| BiGRU | 0.9202 | 0.7844 |
| Ансамбль CNN+LSTM+GRU | 0.9305 | 0.7856 |
| Многозадачная BiLSTM | 0.9145 | 0.7795 |

На полном переносе домена базовая CNN оказалась лучшей. Это важный результат эксперимента: LSTM и GRU полезны для
сравнения и действительно выигрывали в smoke-проверке, но на большом новостном тесте локальные символьные признаки
CNN обобщились лучше. Поэтому для итогового предсказания рекомендуется CNN, а остальные модели оставлены для анализа.
Отдельно в ноутбуке приведена таблица по омонимичным формам и точность десяти морфологических признаков.

Точность морфологических выходов многозадачной LSTM: `Number` 0.977, `Case` 0.890, `Gender` 0.923,
`Animacy` 0.920, `Degree` 0.990, `Aspect` 0.976, `VerbForm` 0.999, `Voice` 0.965, `Tense` 0.979,
`Mood` 0.999. На отобранных омонимах точность составила 0.869 у CNN, 0.842 у LSTM, 0.844 у GRU,
0.858 у ансамбля и 0.857 у многозадачной LSTM.

## Запуск

Установить зависимости:

```bash
pip install -r requirements.txt
```

Открыть `pos_tagging_syntagrus.ipynb` из папки `NLP/pos_tagging` и выбрать ядро
`C:\Users\reino\venvs\nlp_pos\Scripts\python.exe`.

Первый полный запуск разбирает корпуса и обучает недостающие модели. Повторный запуск использует:

- `cache/` — разобранные CoNLL-U-корпуса;
- `models_syntagrus/*.keras` — сохранённые модели;
- `*_history.json` — историю обучения.

Чтобы переобучить одну модель, удалите только соответствующие `*.keras` и `*_history.json`. Чтобы проверить код быстро,
запустите Jupyter с переменной окружения `SMOKE=1`.

## Использование без повторного обучения

### Совсем без установки библиотек (Windows x64)

Скопируйте папку `portable` на ноутбук и запустите `run_pos.bat`, либо из этой папки вызовите:

```powershell
cd portable
./pos_tagger.exe --text "Что делать, если пароль забыт?"
```

Это самодостаточная программа (~35.5 МБ): Python, TensorFlow, NumPy, ONNX Runtime и интернет не нужны.
Внутри находится ONNX-экспорт лучшей CNN. Программа проверена с урезанным `PATH`, без доступа к установленным Python
и пакетам. Подробнее: `portable/README.md`.

### Python без TensorFlow

Если Python уже установлен, для ONNX-варианта достаточно двух лёгких пакетов:

```bash
pip install -r requirements-inference.txt
python predict_pos_onnx.py --text "Что делать, если пароль забыт?"
```

Этот вариант использует `pos_tagging_cnn.onnx` (~0.84 МБ) и не загружает остальные модели. Для повторного экспорта
из новой обученной CNN предусмотрены `export_pos_onnx.py` и `requirements-export.txt`; на целевом ноутбуке они не нужны.

### Полное сравнение моделей

После первоначального обучения можно также использовать TensorFlow-скрипт. Он загружает сохранённые модели и не
переобучает их:

```bash
python predict_pos.py --text "Что делать, если пароль забыт?"
```

Или в Python:

```python
from predict_pos import tag_text
tag_text("Мама читает новую книгу.")
```

`predict_pos.py` загружает только готовые модели и небольшой `vocab_syntagrus.json`; корпуса и обучение не используются.
В результате для каждого слова выводятся варианты CNN, LSTM, GRU, ансамбля и многозадачной LSTM, а также уверенности
и морфологические признаки.

Бинарные модели и кэш не включены в Git из-за размера и пересоздаются ноутбуком. Файл `vocab_syntagrus.json` маленький,
поэтому сохраняется в проекте.

## Омонимия

Омонимичные формы отбираются по SynTagRus: форма должна встречаться минимум 50 раз с двумя частями речи, причём
вторая часть речи должна иметь долю не менее 15%. Для них считается отдельная точность на `nerus_lenta`.

`ruscorpora_content.csv` используется только для качественной проверки: строки с `Ambiguity = "омонимия снята вручную"`
дают реальные контексты, но не содержат UPOS-метки, поэтому по ним нельзя честно посчитать accuracy.
