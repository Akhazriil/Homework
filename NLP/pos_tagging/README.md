# Задание: определение частей речи (POS-tagging)

## Постановка

Программа получает предложение и выводит для каждого слова его часть речи.

- Тексты для обучения — те же, что в задании 1: `examples/Маша и медведь.txt` и `examples/вирус.txt`
  (211 предложений, 3222 токена).
- Разметка — морфологическим анализатором `pymorphy3` (самый вероятный разбор слова),
  теги OpenCorpora сведены к 12 частям речи: NOUN, VERB, ADJ, ADV, PRON, NUM, PREP, CONJ, PART, INTJ, PUNCT, X.
- Фиксированные размеры: `MAX_WORDS = 30` слов в предложении, `MAX_CHARS = 20` символов в слове.
  Короткие слова и предложения дополняются `PAD`, предложения длиннее 30 слов режутся на куски.
- Выход модели для каждого слова — вектор вероятностей по 12 классам (уверенность).

## Модели

**CNN** (`build_cnn`):
1. Embedding символов (размерность 32).
2. Одномерные свёртки по символам слова с ядрами 3, 4, 5 (по 64 фильтра), `GlobalMaxPooling` и конкатенация -> вектор слова (192).
3. Одномерная свёртка (ядро 3, 128 фильтров) по словам предложения.
4. Полносвязный слой (64, ReLU), Dropout 0.3, выходной слой Softmax (12) для каждого слова.

**RNN** (`build_rnn`):
1. Embedding символов с маскированием `PAD`.
2. `Bidirectional(LSTM(64))` по символам слова -> вектор слова (128).
3. `Bidirectional(LSTM(128))` по словам предложения.
4. Dropout 0.3, Softmax (12) для каждого слова.

Обучение: Adam (lr 1e-3), loss — categorical cross-entropy только по реальным словам,
EarlyStopping по `val_loss` (patience 8). Разбиение 70/15/15 по **предложениям**, чтобы одно предложение не попадало сразу в train и test.

## Результаты (тестовая выборка, 542 токена)

| Модель | Точность, все слова | Точность, слова, которых не было в train (242 токена) |
|---|---|---|
| CNN | **0.852** | **0.719** |
| RNN | 0.793 | 0.674 |

Лучше всего распознаются знаки препинания (F1 = 0.98–1.00), предлоги (F1 ≈ 0.91 у CNN) и существительные (F1 ≈ 0.88).
Слабее всего наречия (ADV, F1 ≈ 0.38 у CNN) и редкие классы INTJ и X (в тесте по 1–2 токена).

Графики обучения: `training_history.png`, матрицы ошибок: `confusion_matrices.png`. Полный лог запуска: `run_log.txt`.

## Запуск

```
pip install -r requirements.txt
python pos_tagging.py --text "Маша быстро пошла в лес за грибами, а медведь спал в избушке."
python pos_tagging.py          # интерактивный режим
```

Пример вывода (слово, тег CNN с уверенностью, тег RNN с уверенностью, эталон pymorphy3):

## Выводы

- Символьная свёрточная сеть обобщает морфологию лучше: на незнакомых словах точность 72% против 67% у RNN,
  и она обучается быстрее (примерно 70 эпох против 93, плюс меньше переобучения).
- Ошибки в основном связаны с наречиями и словами, которые могут быть разными частями речи (например, «быстро»,
  где и CNN, и RNN выбирают NOUN, а pymorphy — ADV). Контекст из 30 слов для такой разницы не всегда достаточен.
- Эталонные метки получены автоматически, поэтому точность показывает, насколько сеть повторяет анализатор,
  а не «истинную» грамматику. Это ограничение задания: ручной разметки корпуса нет.
- Корпус небольшой (3222 токена), поэтому редкие классы (INTJ, X) модель почти не выучивает. Для улучшения
  нужен больший корпус (например, `data/MasterAndMargarita.txt`), тогда достаточно поменять `TEXT_FILES`.
