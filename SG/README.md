# Конвертер ABR → XLSX

Десктопное приложение для конвертации файлов .abr (лесустройство) в формат .xlsx.

## Запуск приложения

### Вариант 1: Запуск через Python

1. Установите Python 3.8+ (если не установлен)
2. Создайте виртуальное окружение и установите зависимости:
   ```bash
   python -m venv venv
   venv\Scripts\activate
   pip install openpyxl
   ```
3. Запустите приложение:
   ```bash
   venv\Scripts\python.exe abris_converter_gui.py
   ```

### Вариант 2: Сборка в EXE (для распространения)

1. Запустите скрипт сборки:
   ```bash
   build_exe.bat
   ```
2. После завершения сборки executable файл будет в папке `dist\ABR_Converter.exe`
3. Этот файл можно распространять - он содержит все необходимое для работы

## Использование

1. Нажмите "Обзор..." напротив "Входной файл" и выберите .abr файл
2. Выберите директорию для сохранения результата (по умолчанию - текущая папка)
3. Нажмите "Конвертировать"
4. Результат будет сохранен как `lesoseki.xlsx` в выбранной директории

## Проверки файла

Приложение выполняет следующие проверки:
- Файл выбран
- Файл существует
- Файл имеет расширение .abr
- Выбранный путь является файлом (не папкой)
- Директория для сохранения существует

## Структура проекта

- `abris_converter_gui.py` - GUI приложение (обертка)
- `abris_xl.py` - основной скрипт конвертации
- `build_exe.bat` - скрипт для сборки в EXE
- `requirements.txt` - список зависимостей
